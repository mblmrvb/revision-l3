# Synthèse flash

1. **IAS 1** : pas de modèle imposé mais des rubriques minimales ; distinction **courant / non courant** à l'actif et au passif ; valeurs **nettes**. [Diapo S3 p.8](src:)
2. **BFR** = stocks + créances d'exploitation (y c. charges constatées d'avance) − dettes d'exploitation (y c. produits constatés d'avance). [Diapo S3 p.14](src:)
3. **Endettement net** = dettes financières (courantes et non courantes) − VMP − disponibilités. [Diapo S3 p.15](src:)
4. **Capitaux engagés** = actif économique (actif non courant + BFR) = capitaux propres + endettement net. [Diapo S3 p.15](src:)
5. **Ratios** : structure du passif (CP / dettes, endettement), liquidité (actifs courants ou VMP + dispo / dettes courantes), **ROE = résultat net / capitaux propres** (hors résultat). [Diapo S3 p.16-18](src:)

# Cours

## 1. Le référentiel international

- 1973 : IASC (organisme privé) ; 2000-2001 : réforme, **IASB** ; 2005 : normes obligatoires pour les comptes consolidés des groupes cotés en Europe, sous contrôle de l'EFRAG ; 2021 : **ISSB** (normes de durabilité). [Diapo S3 p.3](src:)
- Un **cadre conceptuel** (inspiré du contexte américain des années 70) fonde les normes : objectifs, caractéristiques qualitatives, éléments, principes de comptabilisation et d'évaluation. [Diapo S3 p.4](src:)
- Il s'appuie sur deux théories : la **théorie de l'agence** (Jensen et Meckling, 1976) — l'information réduit l'asymétrie entre actionnaires et dirigeants — et la **théorie des marchés efficients** (Fama, 1970) — l'information oriente les capitaux vers les meilleures entreprises. [Diapo S3 p.5](src:) [CC nov. 2024, corrigé](src:)
- En France, deux facettes : PME / comptes individuels (PCG) et groupes cotés (IFRS). [Diapo S3 p.6](src:)

## 2. Le format du bilan et la valorisation

- Rubriques minimales, actifs et passifs **courants / non courants**, postes spécifiques (ex. titres mis en équivalence, actifs destinés à être cédés), valeurs nettes. [Diapo S3 p.8](src:)
- **À l'entrée** : juste valeur à l'acquisition. **Ensuite** : soit le coût diminué des amortissements et dépréciations (prudence), soit la juste valeur. [Diapo S3 p.9](src:)
- **Hiérarchie de la juste valeur** : niveau 1 marché actif ; niveau 2 marché équivalent ; niveau 3 valeur actualisée des flux futurs. [Diapo S3 p.9](src:)
- La juste valeur intègre plus-values **et** moins-values potentielles : conflit avec la **prudence**. Le bilan n'est plus une image du patrimoine mais de la **situation financière** à un instant $t$ ; d'où deux résultats : **net** et **global**. Le principe de prudence disparaît du cadre conceptuel en 2010 et revient en 2018. [Diapo S3 p.10-11](src:)

:::methode
**Passer d'un bilan PCG à un bilan IAS 1** (cas AGROTECH) : reclasser chaque poste en courant / non courant **selon son échéance** (notes d'annexe « échéances des dettes ») ; les dettes financières à moins d'un an vont au passif courant ; les provisions sont classées selon leur échéance ; on présente des valeurs nettes ; les concours bancaires courants vont au passif courant. [Poly, cas n°3, note 6](src:)
:::

## 3. Les grandes masses de l'analyse

$$BFR=\text{Stocks}+\text{Créances d'exploitation}+CCA-\text{Dettes d'exploitation}-PCA$$

C'est l'argent **gelé** à un moment donné par le cycle d'exploitation. [Diapo S3 p.14](src:)

$$\underbrace{\text{Actif non courant}+BFR}_{\text{actif économique}}=\text{Capitaux engagés}=\underbrace{\text{Capitaux propres}+\underbrace{\text{Dettes fin.}-VMP-\text{Dispo}}_{\text{endettement net}}}_{\text{passif financier}}$$

[Diapo S3 p.15](src:)

## 4. Les ratios

- **Structure du passif** : CP / dettes (levier), dettes / (CP + dettes) (endettement), dettes financières / total, CP / endettement net… On compare **toujours** deux exercices. [Diapo S3 p.16](src:) [CC oct. 2025, corrigé](src:)
- **Liquidité** : actif courant / passif courant (générale) ; **liquidité immédiate = (VMP + disponibilités) / dettes courantes**. [Diapo S3 p.17](src:) [CC oct. 2025, corrigé](src:)
- **Rentabilité financière** : $ROE=\dfrac{\text{Résultat net}}{\text{Capitaux propres (hors résultat)}}$. [Diapo S3 p.18](src:)

:::exemple
Groupe BALRON (CC oct. 2025) : capitaux engagés = CP 41 286 + (dettes fin. 88 244 − VMP 1 380 − dispo 7 440) = 120 710 en N. Liquidité immédiate = 8 820 / 65 984 = 13,4 % (15,7 % en N-1) : le groupe a puisé dans sa trésorerie pour se désendetter.
:::

# Pièges classiques

- **CBC et VMP dans l'endettement net** : les dettes financières incluent les concours bancaires courants ; on retranche VMP **et** disponibilités. [Diapo S3 p.15](src:)
- **Le BFR exclut** la trésorerie, les VMP, les dettes financières et les provisions non courantes ; il **inclut** CCA et PCA.
- **ROE** : capitaux propres **hors** résultat au dénominateur (selon le cours). [Diapo S3 p.18](src:)
- **Reclassement IAS 1** : la partie à moins d'un an d'une dette financière longue va en **courant**.
- **Un ratio seul ne dit rien** : commente l'évolution N / N-1 et relie-la aux causes (bénéfice qui renforce les CP, remboursement de dette, baisse de trésorerie…).
- **Énoncé long** : repère d'abord la question posée, puis surligne uniquement les postes utiles au calcul demandé.

# Fiche mémo

| Indicateur | Formule |
|---|---|
| BFR | Stocks + Créances exploit. + CCA − Dettes exploit. − PCA |
| Endettement net | Dettes fin. (CT + LT, dont CBC) − VMP − Dispo |
| Capitaux engagés | Actif non courant + BFR = CP + Endettement net |
| Levier / structure | CP / Dettes ; Dettes / (CP + Dettes) ; CP / Endettement net |
| Liquidité générale | Actif courant / Passif courant |
| Liquidité immédiate | (VMP + Dispo) / Dettes courantes |
| ROE | Résultat net / CP hors résultat |

**IAS 1** : courant / non courant, valeurs nettes, rubriques minimales. **JV** : niveau 1 marché actif, 2 marché équivalent, 3 DCF.
